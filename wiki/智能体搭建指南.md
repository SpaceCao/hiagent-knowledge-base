# 智能体搭建指南

智能体的创建、配置和调试完整指南（来源：官方文档中心，可信度：高）。

## 智能体类型

| 类型 | 说明 | 适用场景 |
|------|------|---------|
| 对话型 | 自由对话，按需调用工具 | 问答、助手、聊天 |
| 流程编排型（对话流） | 固定工作流驱动 | 有明确步骤的业务流程 |
| 规划协作型（v2.5.0+） | Planner规划+专家Agent协同 | 搜索调研、长文写作、数据洞察 |
| A2A服务（v2.5.0 beta） | 注册纳管三方A2A服务 | 跨平台Agent协作 |

## 创建智能体

### 方式一：自然语言创建

输入自然语言描述，平台一键生成智能体。

### 方式二：手动创建

1. 进入工作空间 → 智能体 → 创建智能体
2. 选择智能体类型
3. 填写基础信息
4. 配置编排
5. 试运行调试
6. 发布

### 基础配置项

| 配置 | 必填 | 说明 |
|------|------|------|
| 智能体名称 | 是 | 中文/字母/数字/连接符，2-128字符，不可重复 |
| 智能体类型 | 是 | 对话型/流程编排型/规划协作型 |
| 功能介绍 | 是 | 描述智能体功能，帮助LLM理解何时调用 |

## 编排配置

### 对话型智能体

#### 提示词配置

| 配置 | 说明 |
|------|------|
| 角色设定 | 定义智能体身份 |
| 任务描述 | 定义要完成的任务 |
| 工具使用说明 | 何时调用什么工具/知识库 |
| 注意事项 | 纠偏和约束 |
| 输出格式 | markdown/json等 |

#### 提示词优化

支持用大模型自动优化提示词（仅供参考，需人工审核）。

#### 技能配置

| 技能 | 说明 |
|------|------|
| 插件 | 选择已有插件，配置调用参数 |
| 知识库 | 挂载知识库，配置检索参数 |
| 数据库 | 挂载数据库，配置查询参数 |
| 工作流 | 引用已发布工作流 |

#### 模型配置

| 配置 | 说明 |
|------|------|
| 模型选择 | 选择LLM模型 |
| 思维方式 | ReAct / Function_call / Plan and Execute / deep_search |
| 历史对话轮数 | 保留的对话轮数（v2.5.0最大100） |
| max_token | 单次最大输出字数 |
| 随机性 | temperature控制 |
| 迭代次数 | 最大思考轮数 |

#### 对话设置

| 配置 | 说明 |
|------|------|
| 开场白 | 对话开始时展示的内容，支持变量（v2.3.0+） |
| 推荐问题 | 预设推荐问题 |
| 文件上传 | 控制是否允许上传文件及文件类型（v2.2.0+） |
| RAG配置 | 知识库调用方式、检索方式、召回参数 |

### 流程编排型智能体（对话流）

在对话流编排中配置工作流节点：

1. **引用知识库**：支持开启引用开关（v2.4.0+）
2. **节点配置**：配置各节点的输入输出
3. **变量传递**：节点间通过变量传递数据

### 规划协作型智能体（v2.5.0+）

| 配置 | 说明 |
|------|------|
| Planner | 自主规划和监管任务执行 |
| 专家Agent | 专业领域执行 |
| 动态Agent | 按需生成执行 |
| 技能配置 | 可编排插件/知识库/数据库/工作流 |

**注意**：需额外采购或Token包赠送。

## 智能体管理

### 智能体列表功能

- 按属性标签筛选
- 收藏和取消收藏（v2.3.0+）
- 名称关键词模糊搜索
- 复制到其他空间

### 智能体统计指标

| 指标 | 说明 |
|------|------|
| 互动用户数 | 与智能体互动的用户数量 |
| 平均会话互动数 | 每次会话的平均互动次数 |
| 费用消耗 | Token消耗费用 |
| Token输出速度 | 输出效率 |
| 用户满意度 | 基于反馈的满意度 |
| 日志和标注 | 对话日志和用户标注 |
| 内容审核 | 审核记录 |

### A2A服务（v2.5.0 beta）

- 注册纳管三方A2A服务
- 对话型智能体支持A2A服务和本地智能体调用
- 工作流/对话流智能体节点支持A2A服务调用

## 调试技巧

1. **对比调试**（v2.5.0+）：多模型/多提示词对比，直观对比效果
2. **试运行**：必须先试运行才能发布
3. **节点调试**：查看每个节点的输入输出
4. **深度思考折叠**：深度思考过程支持折叠展示（v2.3.0+）

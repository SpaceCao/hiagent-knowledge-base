# 最佳实践

HiAgent 平台使用最佳实践和教程（来源：官方文档中心，可信度：高）。

## 新手入门

### 创建会议助手

1. 创建智能体，选择对话型
2. 编写提示词：角色为会议助手，定义会议记录、总结、待办提取等任务
3. 配置知识库（如需基于会议文档回答）
4. 试运行调试
5. 发布到智能体中心或飞书

### 搭建智能体

1. **需求分析**：明确智能体要解决的问题
2. **选择类型**：对话型/流程编排型/规划协作型
3. **配置技能**：插件、知识库、工作流
4. **编写提示词**：角色、任务、约束
5. **调试优化**：试运行，根据效果迭代
6. **发布上线**：选择渠道发布

## 初级教程

### 搭建AI图片生成应用

**方案**：对话型智能体 + 文生图插件/工作流节点

1. 创建对话型智能体
2. 配置文生图节点或豆包生图插件
3. 提示词定义图片生成规则（风格、尺寸等）
4. 测试不同提示词效果

### 飞书问答助手

**方案**：对话型智能体 + 知识库 + 飞书渠道发布

1. 创建知识库，导入企业文档
2. 创建智能体，挂载知识库
3. 提示词定义角色为问答助手
4. 配置RAG参数（混合检索+Reranker）
5. 发布到飞书机器人渠道

### 微信公众号AI机器人

**方案**：对话型智能体 + 微信渠道发布

1. 创建智能体
2. 配置提示词和技能
3. 发布到微信公众号渠道
4. 配置微信公众号回调地址

### 企业微信应用AI机器人

**方案**：对话型智能体 + 企业微信渠道发布

1. 创建智能体
2. 配置提示词和技能
3. 发布到企业微信渠道
4. 配置企业微信应用参数

## 设计模式

### RAG问答模式

```
用户问题 → 知识库检索 → LLM总结回答
```

**关键配置**：
- 检索方式：混合检索
- Reranker：开启
- RAG范围：3-5
- 召回分段数：5-10

### 多工具协同模式

```
用户问题 → Agent判断 → [插件A] / [插件B] / [知识库] → LLM总结
```

**适用场景**：需要多个数据源/工具的复合问题

### 工作流编排模式

```
[Start] → [信息收集] → [意图识别] → [分支A/B/C] → [End]
```

**适用场景**：有固定流程的业务场景

### Agentic RAG模式

```
用户问题 → [路由Agent] → [知识库A工作流] / [知识库B工作流] → LLM总结
```

**适用场景**：多知识库分路由检索

### 规划协作模式（v2.5.0+）

```
用户问题 → [Planner] → [专家Agent] + [动态Agent] → 协同执行 → 产物输出
```

**适用场景**：搜索调研、长文写作、数据洞察等复杂任务
**注意**：需额外采购或Token包赠送

## 调优技巧

### 提示词优化

1. 明确角色定义，避免模糊
2. 任务描述用编号列表，结构清晰
3. 工具使用说明：什么场景调用什么工具
4. 注意事项用于纠偏，防止常见错误
5. 少样本示例引导输出格式
6. 持续迭代，根据实际效果调整

### 知识库优化

1. 文档预处理：清洗、统一格式、构造分隔符
2. 切片策略：语义完整、大小适中
3. 检索方式：混合检索效果最好
4. Reranker：开启精排提高准确率
5. 图片理解：对图表类内容开启图片理解
6. 标签过滤：利用标签实现精准检索

### 模型选择

1. 智能体底座用非推理类模型（快速响应）
2. 内容分析用推理类模型（深度思考）
3. 工具调用选支持Function Call的模型
4. RAG场景可选deep_search思维方式

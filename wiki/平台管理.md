# 平台管理

管理员视角的平台管理功能概览（来源：官方文档中心，可信度：高）。

## 访问控制

### 用户管理

| 功能 | 说明 |
|------|------|
| 用户列表 | 查看所有用户信息，支持角色筛选 |
| 角色字段 | 展示系统预置租户角色、自定义租户角色、默认角色 |
| 访客切换 | 切换访客有明确提示，可设置访客数据删除时间 |
| 访客角色 | 角色列表新增访客角色展示 |

### 角色管理

| 功能 | 说明 |
|------|------|
| 自定义租户角色 | 包含所有非空间资源点位+空间的查看、创建 |
| 自定义空间角色 | 包含所有空间资源点位+空间的编辑、删除 |
| 默认角色 | 可按作用域分别指定默认角色（租户/工作空间） |
| 复制角色 | 选中角色点击复制，输入名称描述即可创建同权限角色 |
| 身份扮演权限（v2.5.0） | 有该点位的用户通过aksk调用时，可获取所传userid的IAM身份 |

**注意**：平台功能迭代伴随的权限点位更新无法自动同步到自定义角色，需升级后手动校准。

### 组织管理

| 功能 | 说明 |
|------|------|
| 组织搜索定位（v2.5.0） | 搜索后组织树自动展开和滚动定位 |
| 组织自定义排序（v2.5.0） | 同级节点间拖拽调整顺序 |
| 组织层级调整 | 支持按需调整组织层级适配实际架构 |

## 资源管理

### 模型管理

| 功能 | 说明 |
|------|------|
| 模型接入 | 接入豆包/开源/三方模型 |
| 模型服务部署 | 部署推理服务 |
| 服务路由 | 配置模型路由策略 |
| 算力管理 | 独占/共享资源池（v2.5.0+）；华为NPU虚拟化（v2.4.0+） |
| 模型计费 | 支持按token、按图片两种计费单位 |

### 空间管理

| 功能 | 说明 |
|------|------|
| 资源访问范围（v2.5.0） | 添加成员时可限定指定资源和/或自建资源 |
| 知识库额度（v2.4.0） | 支持配置知识库配额上限 |

### 智能体管理

| 功能 | 说明 |
|------|------|
| 批量限流（v2.3.0） | 管理员对智能体批量限流，QPS对勾选智能体全部生效 |
| 条件导出（v2.3.0） | 支持条件搜索、时间范围导出 |

### 标签管理

| 功能 | 说明 |
|------|------|
| 分类与属性拆分（v2.5.0） | 分类=大场景类别，属性=项目/业务标识 |
| 拖拽排序（v2.5.0） | 重排序影响智能体/插件中心展示顺序 |

### 发布管理

| 功能 | 说明 |
|------|------|
| 发布审批 | 智能体发布需审批 |
| 渠道配置 | 配置各渠道发布参数 |
| 访问控制 | Web服务访问范围配置 |

### 干预规则管理

配置全局干预规则，维护敏感词库，保障智能体安全输出。

### Code依赖包管理

租户管理员自助上传Python whl格式依赖包（v2.5.0移至资源管理下）。

## 运营分析

### 数据分析

| 功能 | 说明 |
|------|------|
| 用量分析（v2.5.0） | 多维度查询（组织/用户组/空间/智能体），支持导出 |
| 流量分析（v2.5.0） | 智能体对话分析、Token用量分析、模型调用详情 |
| 知识库统计（v2.2.0） | 知识库总量/文档数/大小/分片数/召回次数 |
| 数据集统计（v2.2.0） | 数据集总量/版本数/数据量 |

### 操作审计（v2.5.0优化）

| 功能 | 说明 |
|------|------|
| 操作对象和详情 | 新增字段 |
| 审计数据补充 | 知识文档下载、用户登录/登出、显示设置修改事件 |
| 清理策略 | 查询最大6个月，存储最大2年，可配置到期清理 |

## 系统管理

### 显示设置

配置平台显示相关参数。

### 第三方认证

| 功能 | 说明 |
|------|------|
| SSO配置 | 支持LDAP、SAML 2.0（v2.4.0+）、企业微信（v2.5.0+） |
| 多SSO（v2.5.0） | 最多10个SSO登录方式，按username合并 |
| 飞书配置 | 配置飞书应用权限scope |

### 系统配置

| 功能 | 说明 |
|------|------|
| 知识库参数 | 文件数量、大小、格式配置 |
| 飞书RedirectURL | 编辑知识库关联飞书App的RedirectURL（v2.4.0+） |
| 域名白屏化配置（v2.4.0） | 运营端支持配置 |
| 观测数据存储周期 | 默认90天，可自定义15~400天 |
| 公告 | 支持Markdown格式，字数限制1000（v2.5.0） |

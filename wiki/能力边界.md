# 能力边界

明确平台支持什么、不支持什么、不确定什么。

## 明确支持

| 能力 | 说明 |
|------|------|
| 智能体创建 | 对话型 / 流程编排型 |
| 思维方式 | ReAct / Plan and Execute / Function_call / deep_search |
| 插件体系 | 官方 / 火山托管 / 三方 / 自定义 / MCP |
| 工作流编排 | 节点式、分支、循环、条件判断、变量传递 |
| 知识库 | 向量/全文/混合检索、Reranker 精排 |
| 多智能体 | 路由 + 子智能体 |
| 发布渠道 | 智能体中心 / 飞书 / 微信 / Web / API |

## 未明确支持

| 能力 | 说明 |
|------|------|
| skills/技能市场 | 无技能封装和复用体系 |
| 版本管理 | 无 prompt 版本对比、配置回滚 |
| 细粒度权限 | 无项目级、插件级、知识库级权限 |
| 批量评测 | 无自动回归、打分仪表盘 |
| 监控日志 | 无运行日志中心、调用 trace、token 监控 |
| 人机协同 | 无人工确认节点、审批节点 |
| 定时任务 | 无定时执行工作流/智能体 |
| 多租户隔离 | 无 workspace、环境隔离 |

## 不确定（需确认）

| 项目 | 说明 |
|------|------|
| MCP 接入细节 | 配置流程、权限策略 |
| 自定义插件封装 | 打包规范、鉴权模板 |
| 工作流条件语法 | 表达式语法、嵌套、并发控制 |
| 知识库高级参数 | 分段长度计量、向量模型选择 |
| 发布后管理 | 灰度、回滚、多版本共存 |
| 多智能体路由 | 分类配置、多标签命中、兜底 Agent |

## 可信度分级

| 来源 | 可信度 | 使用原则 |
|------|-------|---------|
| PDF 原文 | 高 | 作为主要依据 |
| 视频 OCR | 中 | 补充参考，需实际界面确认 |

## 使用原则

1. 设计方案时只使用"明确支持"的能力
2. "未明确支持"的能力不能假设存在
3. "不确定"的能力需要用户在平台确认

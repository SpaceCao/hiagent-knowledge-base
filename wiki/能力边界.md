# 能力边界

明确平台支持什么、不支持什么、不确定什么。
> 基于 v2.5.0 ReleaseNote 更新，来源可信度：高

## 明确支持

| 能力 | 说明 |
|------|------|
| 智能体创建 | 对话型 / 流程编排型 / **规划协作型**（v2.5.0+） |
| 思维方式 | ReAct / Plan and Execute / Function_call / deep_search |
| 插件体系 | 官方 / 火山托管 / 三方 / 自定义 / MCP / **高代码MCP**（v2.5.0+） |
| 工作流编排 | 节点式、分支、循环、条件判断、变量传递、**异常兜底分支**（v2.5.0+） |
| 知识库 | 向量/全文/混合检索、Reranker精排、**图文混搜**（v2.3.0+）、**多模态rerank**（v2.5.0+） |
| 多智能体 | 路由+子智能体 / **规划协作型**（v2.5.0+） / **A2A服务**（v2.5.0 beta） |
| 发布渠道 | 智能体中心 / 飞书 / 微信 / Web / API / **A2A**（v2.5.0+） |
| 评测 | **在线评测**、**安全评测**（v2.5.0+需额外采购）、**评估器**（含Agent评估器） |
| 观测 | **链路追踪**、**告警监控**（v2.5.0+）、**知识看板**（v2.5.0+） |
| 数据 | **智能合成数据集**（v2.5.0+）、数据标注、数据回流 |
| 算力管理 | **独占/共享资源池**（v2.5.0+）、华为NPU虚拟化（v2.4.0+） |
| 运行态部署 | 独立部署、**导入数据**、**长期记忆**、**HPA**（v2.5.0+） |
| 安全 | **大模型应用防火墙**（v2.5.0+）、**加密服务**（v2.5.0+）、字段加密（v2.4.0+） |
| SSO | LDAP / SAML 2.0（v2.4.0+） / 企业微信（v2.5.0+） / 多SSO（v2.5.0+） |

## 未明确支持

| 能力 | 说明 |
|------|------|
| skills/技能市场 | 无技能封装和复用体系 |
| 版本管理 | 无 prompt 版本对比、配置回滚 |
| 细粒度权限 | 无项目级、插件级权限（已有知识库/数据库级别权限） |
| 定时任务 | 无定时执行工作流/智能体 |
| 多租户隔离 | 无 workspace、环境隔离 |

## 不确定（需确认）

| 项目 | 说明 |
|------|------|
| MCP Marketplace兼容性 | 部分MCP可能无法兼容平台运行环境 |
| 自定义插件封装 | 打包规范、鉴权模板 |
| 工作流条件语法 | 表达式语法、嵌套、并发控制 |
| 发布后管理 | 灰度、回滚、多版本共存 |
| 多智能体路由 | 分类配置、多标签命中、兜底 Agent |

## 可信度分级

| 来源 | 可信度 | 使用原则 |
|------|-------|---------|
| PDF 原文 / 官方文档 | 高 | 作为主要依据 |
| 视频 OCR | 中 | 补充参考，需实际界面确认 |

## 使用原则

1. 设计方案时只使用"明确支持"的能力
2. "未明确支持"的能力不能假设存在
3. "不确定"的能力需要用户在平台确认
4. 需额外采购的能力需提前确认采购状态

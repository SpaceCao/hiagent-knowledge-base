# 参数配置

智能体创建后的核心配置项。

## 思维方式

| 方式 | 说明 | 适用场景 |
|------|------|---------|
| ReAct | 自由调用工具/知识库 | 绝大多数场景 |
| Function_call | 结构化工具调用 | 需模型支持，标准化输出 |
| Plan and Execute | 先计划后执行 | 复杂多步骤任务 |
| deep_search | 自动拆解多轮检索 | 搭配搜索插件/知识库 |

**注意**：Function_call 需模型支持，不支持时会回退到 ReAct。

## 关键参数

### 输出控制

| 参数 | 推荐值 | 说明 |
|------|-------|------|
| max_token | 4096 | 单次最大输出字数 |
| 随机性/核采样 | 按需 | temperature 和 top_p 不推荐同时调整 |

### 记忆控制

| 参数 | 推荐值 | 说明 |
|------|-------|------|
| 对话轮数保留 | 30（最大） | 历史对话保留轮数 |
| RAG 范围 | 3 | 多轮对话带入知识库检索，值越大越相关但 token 消耗越高 |

### 执行控制

| 参数 | 说明 |
|------|------|
| 迭代次数 | 智能体最多思考轮数，复杂任务需调大 |

## RAG 范围详解

- 范围 1-10
- 打开：携带历史问答检索
- 关闭：仅用当前问题检索
- 建议：一般设 3，充分背景检索设最高

## 系统变量

可在 Prompt 中引用的用户信息：

| 变量 | 说明 | 可信度 |
|------|------|--------|
| SYS_USERID | 用户 ID | 中（视频 OCR） |
| SYS_USERNAME | 用户名 | 中（视频 OCR） |
| TARPID / FamPID | 租户/组织标识 | 中（视频 OCR） |

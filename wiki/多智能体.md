# 多智能体

多个智能体协作，处理任务类型差异大的场景。

## 适用场景

- 任务类型差异大
- 不同领域知识
- 不同工具需求

## 编排结构

```
[路由 Agent] ─→ 判断问题类型
    │
    ├─→ [智能体A] → 领域A问题
    │
    ├─→ [智能体B] → 领域B问题
    │
    └─→ [智能体C] → 领域C问题
```

## 配置步骤

1. 在编排配置中选择"多 Agent 模式"
2. 第一个节点是路由，判断问题类型（必选）
3. 添加已发布智能体，或现场新建
4. 配置问题转发逻辑

## 路由 Agent

- 默认必选
- 判断用户问题属于哪个类型
- 将问题转发给对应智能体

## 子智能体来源

- 已发布智能体
- 现场新建智能体

## 设计要点

1. 子智能体需要先发布
2. 路由 Agent 的 Prompt 要清晰定义分类规则
3. 各子智能体职责边界要明确

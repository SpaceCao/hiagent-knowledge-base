# 多智能体

多个智能体协作，处理任务类型差异大的场景。

## 适用场景

- 任务类型差异大
- 不同领域知识
- 不同工具需求
- 复杂任务需要规划和协作

## 编排结构

### 路由模式

```
[路由 Agent] ─→ 判断问题类型
    │
    ├─→ [智能体A] → 领域A问题
    │
    ├─→ [智能体B] → 领域B问题
    │
    └─→ [智能体C] → 领域C问题
```

### 规划协作模式（v2.5.0+）

```
[Planner] ─→ 自主规划和监管
    │
    ├─→ [专家Agent] → 专业领域任务
    │
    ├─→ [动态Agent] → 按需生成执行
    │
    └─→ 协同完成复杂任务
        （搜索调研、长文写作、数据洞察等）
```

- 支持编排配置插件、知识库、数据库、工作流等技能
- 支持清晰展示任务执行过程和产物
- **需额外采购或Token包赠送**

### A2A服务模式（v2.5.0 beta）

```
[本地智能体] ─→ 调用 ─→ [三方A2A服务]
    │
    └─→ 注册纳管三方A2A服务
```

- 对话型智能体支持A2A服务和本地智能体调用
- 工作流/对话流智能体节点支持A2A服务调用

## 配置步骤

1. 在编排配置中选择"多 Agent 模式"
2. 第一个节点是路由，判断问题类型（必选）
3. 添加已发布智能体，或现场新建
4. 配置问题转发逻辑

## 路由 Agent

- 默认必选
- 判断用户问题属于哪个类型
- 将问题转发给对应智能体

## 子智能体来源

- 已发布智能体
- 现场新建智能体
- 三方A2A服务（v2.5.0+）

## 设计要点

1. 子智能体需要先发布
2. 路由 Agent 的 Prompt 要清晰定义分类规则
3. 各子智能体职责边界要明确
4. 规划协作型智能体的Planner负责整体任务拆分和监管
5. A2A服务需先注册纳管

# 开发指南

HiAgent 开放集成和二次开发能力汇总（来源：官方文档中心，可信度：高）。

## 开放集成能力

HiAgent 提供完整的开放集成能力，包括：

| 集成类型 | 说明 |
|---------|------|
| 自有模型适配 | 接入企业自有大模型 |
| 自有渠道适配 | 将智能体嵌入自有系统 |
| 插件接入 | 封装企业API为HiAgent插件 |
| 前端自定义 | 定制平台前端展示 |
| 审批系统对接 | 对接三方审批流程 |
| SSO/组织同步 | 对接企业身份认证和组织架构 |
| 知识库适配 | 替换OCR/解析服务、链接外部知识库 |
| 数据同步 | 观测数据导出、数据表结构 |
| SDK集成 | Python/Java SDK |
| 运行态部署 | 独立部署智能体运行环境 |

## 自有模型适配

### 标准模型接入

支持OpenAI兼容接口的模型可直接接入。

### 非标准模型适配

通过适配层接入非标准模型，支持自定义请求/响应格式转换。

## 自有渠道适配

### iframe嵌入

将HiAgent智能体Web服务通过iframe嵌入三方平台。

### WEBSDK嵌入

HiAgent智能体WebSDK iframe嵌入已有平台，支持：
- `variables` 自定义参数值传递（v2.4.0+）
- 访问控制对websdk生效（v2.4.0+）

### 自有渠道接入开发手册

完整的渠道接入开发指南，包含：
- 认证鉴权流程
- API调用规范
- 消息格式定义
- 错误码说明

## 插件接入

### 自有插件接入

将企业已有API封装为HiAgent自定义插件：
1. 创建插件定义（名称、描述、鉴权方式）
2. 定义工具（API端点、请求参数、响应格式）
3. 配置鉴权信息（API Key / OAuth / BYOK）
4. 测试工具可用性

## 前端自定义

### ViewMode配置文件

配置前端展示模式，支持：
- 隐藏/显示导航栏
- 自定义loading页开关
- 配置页面布局

### 平台前端嵌入

将HiAgent平台前端页面嵌入已有平台，支持postmessage自定义导航（v2.3.0+）。

### 显示配置

- 平台端显示配置
- 运营端显示配置

## 审批系统对接

HiAgent发布对接三方审批系统，支持配置审批回调接口。

## SSO与组织信息同步

### SSO适配

| 协议 | 说明 |
|------|------|
| LDAP | 基础SSO |
| SAML 2.0 | v2.4.0+支持 |
| 企业微信 | v2.5.0+支持 |
| 多SSO | 最多10个SSO，按username合并 |
| SSO退出回调 | 外部系统退出时联动HiAgent退出 |

### 组织信息同步

支持从SSO系统同步组织架构信息到HiAgent。

### 自定义平台角色

支持自定义租户角色和空间角色。

### 组织结构层级调整

支持按需调整组织层级，适配企业实际架构。

## 知识库适配

### 替换OCR服务

支持替换知识库的OCR解析服务为自定义服务。

### 替换自定义解析服务

| 版本 | 说明 |
|------|------|
| v2.0.0~v2.1.0 | 旧版自定义解析接入 |
| v2.2.0+（推荐） | 新版自定义解析接入，通过SDK实现 |

### 链接外部知识库

支持HiAgent链接外部知识库，实现跨系统知识检索。

## 数据同步

### 观测数据导出

支持导出智能体运行观测数据，包含：
- 链路追踪数据
- Token消耗数据
- 会话数据

### 数据表结构

提供组织、智能体、Token消耗相关数据表结构说明文档，方便企业做数据分析。

## SDK集成

### Python SDK

| SDK | 说明 |
|-----|------|
| HiAgent Python SDK | 平台管理SDK（空间/智能体/知识库等） |
| HiAgent对话Python SDK | 智能体对话调用SDK |

### Java SDK

| SDK | 说明 |
|-----|------|
| HiAgent Java SDK | 平台管理SDK |
| HiAgent对话Java SDK | 智能体对话调用SDK |

## 运行态部署（v2.5.0）

独立部署智能体运行环境：
- 支持导入知识库/数据库/问答库数据
- 支持长期记忆能力
- 镜像拆分结合指标监控实现HPA
- 配置项详细说明

## 触发器解耦与回调接入

支持触发器解耦部署和回调接入方案。

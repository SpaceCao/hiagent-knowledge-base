# 模型选择

选择合适的大语言模型是智能体设计的第一步。

## 模型分类

### 非推理类模型

直接回答问题，适合智能体底座。

| 模型 | 说明 |
|------|------|
| Claude-opus-4 | Anthropic 旗舰 |
| ChatGPT-4o-latest | OpenAI 最新 |
| Doubao-seed-1.6（关闭思考） | 豆包，思考可控制 |
| Doubao-1.5-pro-32k | 豆包，32k 上下文 |
| deepseek-v3 | 深度求索，64k 上下文 |
| Qwen | 通义千问 |

**适用场景**：日常问答、智能体底座、快速响应

### 推理类模型

先思考再回答，适合复杂任务。

| 模型 | 说明 |
|------|------|
| Deepseek-R1 | 深度求索推理版 |
| o3 | OpenAI 推理模型 |
| o4-mini(high) | OpenAI 轻量推理 |
| Doubao-seed-1.6（开启思考） | 豆包推理模式 |
| QwQ-32B | 通义推理版 |
| Gemini-2.5-pro | Google 推理模型 |

**适用场景**：文案撰写、数据分析、长文生成

## 选择建议

```
场景判断
    │
    ├─ 智能体底座 ────→ 非推理类
    │
    ├─ 快速响应 ──────→ 非推理类
    │
    ├─ 文案/分析 ─────→ 推理类
    │
    └─ 复杂推理 ──────→ 推理类
```

## 关键特性

| 特性 | 说明 |
|------|------|
| 上下文窗口 | 单次可处理文本长度，如 32k、64k |
| 输出限制 | 单次输出 token，常见 4096/8192 |
| 随机性控制 | temperature / top_p |
| Function Call | 结构化工具调用，需模型支持 |

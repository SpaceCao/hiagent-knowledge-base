# 版本更新记录

HiAgent 平台版本功能更新汇总（来源：官方文档中心，可信度：高）。

## v2.5.0

### 智能体搭建

| 功能 | 说明 |
|------|------|
| 规划协作型智能体 | Planner 自主规划监管下，专家Agent+动态Agent协同完成复杂任务（搜索调研、长文写作、数据洞察等）。支持编排插件/知识库/数据库/工作流技能。**需额外采购或Token包赠送** |
| 多模型/多提示词对比调试 | 对话型智能体支持对比调试，直观对比效果 |
| 智能体标签 | 管理支持设置标签，标签由租户管理员预定义，暂不支持空间用户自定义 |
| 触发器超时扩展 | 执行超时从1分钟最大到30分钟，可智能体维度单独配置 |
| 发布审批优化 | 拆分配置发布和渠道发布步骤；新增发布tab；支持更细粒度审批渠道配置 |
| 编排模型配置优化 | 接入服务路由模式；历史对话轮数最大从30到100 |
| API透传自定义header | 请求header以X-Trace-\***规则命名会默认透传 |
| 自定义上传文件后缀 | 智能体维度自定义上传文件格式（需自己控制上传文件的执行风险） |
| 大模型应用防火墙 | 支持对接云上SAAS版本大模型应用防火墙 |
| A2A服务[beta] | 注册纳管三方A2A服务；对话型智能体支持A2A服务和本地智能体调用；工作流/对话流智能体节点支持A2A服务调用 |
| 运行态独立部署升级 | 支持导入知识库/数据库/问答库数据；支持长期记忆能力；镜像拆分结合指标监控实现HPA |
| WebApp知识库预览 | 支持拖拽引用的知识库文件预览区域宽度和全屏预览 |

| 视频生成节点声音 | 新增声音能力，依赖豆包视频生成模型 |

| 兼容预编译符 | 重写拉取表结构SQL，兼容Doris/Starrocks等不支持预编译符的数据库 |

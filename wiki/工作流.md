# 工作流

节点式流程编排，实现固定业务流程的自动化。

## 核心概念

工作流是一系列有序的任务和操作，支持分支、循环和条件判断。

**适用场景**：有固定工作流程的业务场景

## 节点类型

| 节点 | 用途 | 版本 |
|------|------|------|
| 开始节点 | 定义输入变量 | 初始 |
| 大模型节点 | 调用 LLM 处理 | 初始 |
| 插件节点 | 调用外部工具 | 初始 |
| 知识库节点 | 检索知识 | 初始 |
| 消息节点 | 输出中间结果/进度提示 | 初始 |
| 终止节点 | 输出最终结果或返回外部智能体 | 初始 |
| 信息收集节点 | 直接回答/选项回答，参数抽取 | v2.3.0 |
| 意图识别节点 | 识别用户意图并路由 | v2.3.0+排序 |
| 文生图节点 | 生成图片（豆包模型） | v2.2.0 |
| 视频生成节点 | 文生视频/图生视频 | v2.3.0 |
| 文本处理节点 | 文本拼接和分割 | v2.5.0 |
| 循环节点 | 数值循环/指定次数循环/无限循环 | v2.3.0增强 |

## 变量传递

- 开始节点定义输入变量
- 后续节点可引用任何上游节点的输出
- 大模型节点的 Prompt 可引用工作流变量
- **v2.5.0**：Start节点单个变量支持多类型文件（default类型不约束文件类型）

### 变量类型语法

```
变量名        类型
─────────────────────
avatar_url   Array<String>
name_cn      Array<String>
user_key     String
```

### 自定义参数（v2.2.0+）

- 意图识别和数据库节点支持新增自定义参数
- 自定义参数后可在高级设置引用此参数值

## 常见结构

### 多工具并行/串行 + 大模型整理

```
[开始] → [插件A] ─┐
                 ├→ [大模型整理] → [终止]
[插件B] ─────────┘
```

**案例**：AI 搜索引擎，搜索多渠道后梳理报告

### 多大模型串行计划/反思

```
[开始] → [大模型-计划] → [大模型-执行] → [大模型-反思] → [终止]
```

**案例**：
- 反思-高质量代码生成
- 长文生成智能体
- 类 o1 慢思考智能体

## 节点详细配置

### Start节点

工作流起始节点，定义启动参数。

| 配置 | 说明 |
|------|------|
| 变量名 | 字母/数字/连接符，1-128字符 |
| 变量类型 | String/Integer/Number/Object/Boolean/File/Array系列 |
| 描述 | 变量描述，1-128字符 |
| 必填 | 是否必填参数 |
| 添加子项 | Object类型可添加子参数，最多两级嵌套 |

**File类型明细**：

| 子类型 | 格式 |
|--------|------|
| Default（不限） | 所有支持的文件类型 |
| Image | png/jpg/jpeg/gif/svg/webp/bmp |
| Doc | pdf/doc/docx/ppt/pptx/ofd/csv/xls/xlsx |
| Txt | html/txt/md/json/xml |
| Voice | wav/ogg/mp3/aac/m4a |
| Video | mp4/avi/mov/flv/wmv/rmvb/webm/mpga |
| Code | py/java/c/cpp/js/css |
| Zip | rar/zip/7z/gz/gzip |

- v2.5.0：单个变量支持多类型文件（default不约束文件类型）
- 复杂参数层级至多5层

### End节点

工作流终止节点，返回结果。

| 回复模式 | 说明 |
|---------|------|
| 使用设定的内容直接回答 | 直接输出设定内容，可引用变量`{{output}}` |
| 返回变量，由智能体生成回答 | 交由智能体LLM总结回答 |

### LLM节点

调用大模型处理，最核心的节点。

| 配置 | 说明 |
|------|------|
| 节点名称 | 标识节点 |
| 模型 | 选择LLM模型 |
| 模型参数 | temperature/max_token等 |
| 系统提示词 | 角色和任务定义 |
| 用户提示词 | 具体问题，可引用变量 |

- 支持视频理解能力（v2.2.0+）
- 支持节点级超时和重试（v2.2.0+）

### 代码节点

执行自定义Python代码。

- 支持租户管理员上传whl依赖包（v2.2.0+，需NFS）
- 支持节点级超时和重试（v2.2.0+）
- 依赖包生效范围：工作流代码节点/评测代码评估器/数据处理代码节点

### 插件节点

调用已配置的插件工具。

- 可选择空间内已有插件
- 配置工具参数
- 支持流式输出

### 知识库节点

检索知识库内容。

| 配置 | 说明 |
|------|------|
| 知识库选择 | 选择挂载的知识库 |
| 检索方式 | 向量/全文/混合 |
| 召回数量 | 返回的分段数 |
| 调试参数 | 支持编辑知识库标签或参数（v2.5.0+） |

### 信息收集节点（v2.3.0+）

| 模式 | 说明 |
|------|------|
| 直接回答 | 参数抽取模式/无需抽取模式 |
| 选项回答 | 非分支模式/分支模式（根据选项路由到不同下游） |

- 参数抽取：支持多轮抽取
- 选项回答分支：不同选项可路由至不同下游分支

### 意图识别节点

识别用户意图并路由到不同分支。

- 支持拖拽调整意图顺序（v2.3.0+）
- 支持自定义参数（v2.2.0+）

### 循环节点（v2.3.0增强）

| 类型 | 说明 |
|------|------|
| 数值循环 | 按数组迭代 |
| 指定次数循环 | 固定次数，最大1000次 |
| 无限循环 | 结合终止循环节点基于条件设置，达1000次自动终止 |

- 调试结果支持按item切换查看（v2.5.0+）

### 消息节点

输出中间进度提示。

- 支持内层消息节点输出到对话框（v2.2.0+）
- 支持reasoning渲染效果（v2.2.0+）
- 可控制是否作为多轮对话上下文（v2.2.0+）

### 文生图节点（v2.2.0）

- 支持豆包文生图模型
- 图生图/多图生成/宽高/分辨率模式（v2.4.0+）
- 支持doubao-seedream-4.0模型（v2.4.0+）

### 视频生成节点（v2.3.0）

- 支持文生视频和图生视频
- 视频生成模型由模型管理接入
- 新增声音能力（v2.5.0+，依赖豆包视频生成模型）
- 多参考图/首尾帧（v2.4.0+）

### 文本处理节点（v2.5.0）

- 支持文本拼接和分割能力

## 节点级配置

| 配置 | 说明 | 版本 |
|------|------|------|
| 超时时间 | LLM/代码/意图识别/文生图节点可单独设置 | v2.2.0 |
| 重试次数 | LLM/代码/意图识别/文生图节点可单独设置 | v2.2.0 |
| 异常忽略 | HTTP节点自定义状态码；异常分支逻辑兜底 | v2.5.0 |

## 调试与发布

1. **试运行**：必须先试运行才能发布
2. **节点调试**：查看每个节点的输入输出
3. **发布**：试运行通过后发布，才能挂到智能体
4. **强制发布**（v2.3.0+）：未经调试也可直接发布，适用导入/导出场景
5. **异常检测**（v2.4.0+）：查看全局存在异常配置的节点汇总
6. **调试记录清理**（v2.4.0+）：可配置15~400天

## 性能

- v2.2.0：画布性能优化，支持百级别节点
- v2.5.0：正常配置下单画布节点承载量可达200+

## 设计要点

1. 消息节点用于展示中间进度
2. 终止节点可选择直接输出或返回外部智能体
3. 复杂任务迭代次数要设置足够大
4. 消息节点输出内容可配置reasoning渲染效果（v2.2.0+）
5. 消息节点可控制是否作为多轮对话上下文（v2.2.0+）
6. LLM节点支持视频理解能力（v2.2.0+）

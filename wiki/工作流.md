# 工作流

节点式流程编排，实现固定业务流程的自动化。

## 核心概念

工作流是一系列有序的任务和操作，支持分支、循环和条件判断。

**适用场景**：有固定工作流程的业务场景

## 节点类型

| 节点 | 用途 |
|------|------|
| 开始节点 | 定义输入变量 |
| 大模型节点 | 调用 LLM 处理 |
| 插件节点 | 调用外部工具 |
| 知识库节点 | 检索知识 |
| 消息节点 | 输出中间结果/进度提示 |
| 终止节点 | 输出最终结果或返回外部智能体 |

## 变量传递

- 开始节点定义输入变量
- 后续节点可引用任何上游节点的输出
- 大模型节点的 Prompt 可引用工作流变量

### 变量类型语法

```
变量名        类型
─────────────────────
avatar_url   Array<String>
name_cn      Array<String>
user_key     String
```

## 常见结构

### 多工具并行/串行 + 大模型整理

```
[开始] → [插件A] ─┐
                 ├→ [大模型整理] → [终止]
[插件B] ─────────┘
```

**案例**：AI 搜索引擎，搜索多渠道后梳理报告

### 多大模型串行计划/反思

```
[开始] → [大模型-计划] → [大模型-执行] → [大模型-反思] → [终止]
```

**案例**：
- 反思-高质量代码生成
- 长文生成智能体
- 类 o1 慢思考智能体

## 调试与发布

1. **试运行**：必须先试运行才能发布
2. **节点调试**：查看每个节点的输入输出
3. **发布**：试运行通过后发布，才能挂到智能体

## 设计要点

1. 消息节点用于展示中间进度
2. 终止节点可选择直接输出或返回外部智能体
3. 复杂任务迭代次数要设置足够大

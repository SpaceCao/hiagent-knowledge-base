# 常见问题

HiAgent 平台常见问题和解决方案（来源：官方文档中心，可信度：高）。

## 智能体

### ReAct、Function Call、Plan And Execute 有什么区别？

| 方式 | 原理 | 优势 | 劣势 |
|------|------|------|------|
| ReAct | Thought→Action→Observation多轮循环 | 通用，不依赖模型特殊能力 | 可能不够稳定 |
| Function Call | 模型官方API工具调用，经过精调 | 工具调用更强更稳定 | 需模型支持 |
| Plan And Execute | Planner生成计划→Executer依次执行 | 适合复杂问题 | 耗时较长 |

**选择建议**：
- 有Function Call的模型优先用Function Call
- Function Call解决不了的复杂问题尝试Plan And Execute
- deep_search适合RAG场景，不建议开启模型长思考

### 模型不听指令怎么办？

1. 模型本身遵循指令能力差异 - 换更强的模型
2. 上下文过多影响 - 精简提示词/知识库召回/工具输出
3. 提示词写法优化 - 让模型更容易理解

### 智能体直接返回工作流结果？

End节点选择"使用设定的内容直接回答"，在回答内容中用变量引用：
```
{{output}}
```

### 在对话流中展示知识库召回的图片？

在大模型节点用户提示词中添加图片引用规则：
- 识别`<img src="">`标签和markdown图片引用
- 输出格式：`![图片名称](图片地址)`
- 引用检索分段格式：`[1][3][5]`

### 智能体多轮对话记忆机制？

- 通过对话轮数参数控制保留的历史对话轮数
- v2.5.0最大支持100轮（原30轮）

## 工作流

### 工作流节点类型有哪些？

| 节点 | 用途 |
|------|------|
| Start | 定义输入变量 |
| LLM | 调用大模型 |
| 插件 | 调用外部工具 |
| 知识库 | 检索知识 |
| 消息 | 中间输出/进度提示 |
| End | 输出最终结果 |
| 信息收集 | 参数收集/选项回答 |
| 意图识别 | 识别意图并路由 |
| 代码 | 执行自定义代码 |
| 文生图 | 生成图片 |
| 视频生成 | 生成视频 |
| 文本处理 | 文本拼接/分割 |

### 工作流执行异常如何处理？

- v2.5.0+：配置异常分支逻辑兜底
- HTTP节点：自定义请求状态码判断异常
- 节点级超时和重试设置（v2.2.0+）

## 知识库

### 知识库支持哪些文件格式？

| 类型 | 格式 |
|------|------|
| 文档 | PDF/WORD/PPT/Excel/CSV/XML/WPS |
| 飞书 | 云文档/多维表格/知识库/云盘文件 |
| 视频 | 需配置ASR模型 |
| 图片 | 支持图片理解 |

### 知识库检索方式怎么选？

| 方式 | 适用 | 建议 |
|------|------|------|
| 向量检索 | 语义匹配 | 图文混搜推荐 |
| 全文检索 | 精确关键词 | 关键词明确的场景 |
| 混合检索 | 综合效果 | 大多数场景效果最好 |

### 知识库图片理解能力？

- 支持多模态Embedding模型+图片向量化（v2.3.0+）
- 图片要求长宽>=150px
- 支持图表深度解析，生成拟合数据表（v2.4.0+）

### 解析服务怎么选？

| 服务 | 效果 | 成本 |
|------|------|------|
| PaddleOCR-VL（v2.5.0） | 最优 | 需GPU/NPU |
| VLM解析（v2.4.0） | 业界最优 | 需GPU |
| 内置解析 | 标准 | 无额外成本 |
| Textin | 较好 | 需采购 |

## 插件

### 插件类型有哪些？

| 类型 | 说明 |
|------|------|
| 官方插件 | 平台内置 |
| 火山托管 | 云服务 |
| MCP | 标准协议 |
| 自定义 | 自有API封装 |
| 高代码MCP | 上传代码包运行 |

### 自定义插件怎么创建？

1. 创建插件（名称、描述、鉴权）
2. 定义工具（API端点、参数、响应格式）
3. 配置鉴权（API Key / OAuth / BYOK）
4. 测试发布

### MCP不兼容的场景？

- 需要读本地文件系统
- 需要使用本地操作系统功能
- 启动命令非uvx/npx/docker

### 请求体格式怎么选？

| 格式 | 说明 |
|------|------|
| json | JSON格式（默认） |
| form-data | 表单上传 |
| x-www-form-urlencoded | URL编码表单 |
| None | 不传Content-type，忽略Body |

## 提示词

### Prompt怎么写更好？

1. **角色定义清晰** - 明确智能体身份和定位
2. **任务描述具体** - 定义要完成的具体任务
3. **工具使用说明** - 说明何时调用什么工具
4. **约束和注意事项** - 纠偏和稳定输出
5. **少样本示例** - 引导行为和格式

### 输出格式怎么控制？

- 在Prompt中规定输出结构（markdown/json等）
- 使用消息节点的直接输出模式
- End节点选择"使用设定的内容直接回答"

## SSO

### 支持哪些SSO协议？

- LDAP（默认）
- SAML 2.0（v2.4.0+）
- 企业微信（v2.5.0+）
- 最多10个SSO登录方式（v2.5.0+）

### 多SSO如何处理？

- 按username合并同一用户
- 无法开启强制SSO登录
- 登录异常跳转错误页

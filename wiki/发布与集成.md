# 发布与集成

将智能体发布到各渠道，供用户使用。

## 发布渠道

| 渠道 | 说明 |
|------|------|
| 智能体中心 | 平台内部使用 |
| 飞书 | 企业通讯工具（v2.3.0+: 支持新建会话事件配置） |
| 微信 | 社交平台 |
| Web 服务 | 网页对话入口 |
| 后端 API | 供其他系统调用 |
| A2A服务 | 注册纳管三方A2A服务（v2.5.0 beta） |

## 发布审批（v2.5.0优化）

- 拆分智能体配置发布和渠道发布步骤
- 新增智能体发布tab，可单独配置发布和查看已发布渠道
- 支持更细粒度审批渠道配置

## Web 服务

- 即时 Web 网页
- 点击预览可看到对话界面
- 直接与智能体问答

### Web 访问控制（v2.3.0+）

- 租户管理员可配置web服务允许发布的生效范围
- 可隐藏匿名用户访问选项

### WEBSDK（v2.4.0+）

- 支持通过`variables`进行自定义参数值传递
- 访问控制对websdk同时生效
- 由只支持匿名访问，扩展可支持平台认证用户、平台指定用户

## 后端 API

将智能体问答能力封装成 API，可在其他系统调用。

**适用场景**：
- 嵌入自有产品
- 与业务系统集成
- 批量调用

### API 增强

| 功能 | 说明 | 版本 |
|------|------|------|
| 透传自定义header | X-Trace-\***命名的header默认透传 | v2.5.0 |
| UserID中文 | chat_query接口UserID参数支持中文 | v2.3.0 |

## 飞书集成

| 功能 | 说明 | 版本 |
|------|------|------|
| 新建会话事件 | 发布到飞书机器人后可配置 | v2.3.0 |
| openid/userid互联 | 支持互联 | v2.4.0 |
| OAuth2授权 | 支持用户OAuth2获取user_access_token | v2.2.0 |

## SSO 集成

| 协议 | 说明 | 版本 |
|------|------|------|
| SAML 2.0 | 支持集成 | v2.4.0 |
| 企业微信 | 兼容企业微信SSO登录 | v2.5.0 |
| 多SSO | 支持最多10个SSO登录方式，按username合并 | v2.5.0 |
| SSO免登录 | 透传Token实现免登录 | v2.2.0 |
| SSO退出回调 | 外部系统退出时联动HiAgent退出 | v2.3.0 |

## 嵌入集成

| 方式 | 说明 | 版本 |
|------|------|------|
| iframe嵌入 | 智能体Web服务通过iframe嵌入三方平台 | 初始 |
| WEBSDK iframe | HiAgent智能体WebSDK iframe嵌入已有平台 | 初始 |
| postmessage | 前端自定义导航，打开任意详情页 | v2.3.0 |

## 运行态独立部署（v2.5.0升级）

- 支持运行态部署时导入知识库/数据库/问答库数据
- 支持运行态长期记忆能力
- 运行态部署镜像拆分结合指标监控实现HPA
- 流程编排型智能体支持发布为运行部署包（v2.4.0+）

## 数据安全

| 功能 | 说明 | 版本 |
|------|------|------|
| 加密服务接入 | 提供加密/解密服务接口规范 | v2.5.0 |
| 数据表字段加密 | 支持非对称加密字段存储和检索 | v2.4.0 |
| 大模型应用防火墙 | 支持对接云上SAAS版本 | v2.5.0 |

## 版本差异

2.1.0 以下版本的发布渠道和 Web/API 位置可能不同，具体参考对应版本帮助文档。

## 发布流程

```
智能体配置完成
    │
    ↓
点击"发布与集成"
    │
    ↓
选择发布渠道
    │
    ↓
配置渠道参数
    │
    ↓
审批（如需）
    │
    ↓
发布上线
```

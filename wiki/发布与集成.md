# 发布与集成

将智能体发布到各渠道，供用户使用。

## 发布渠道

| 渠道 | 说明 |
|------|------|
| 智能体中心 | 平台内部使用 |
| 飞书 | 企业通讯工具 |
| 微信 | 社交平台 |
| Web 服务 | 网页对话入口 |
| 后端 API | 供其他系统调用 |

## Web 服务

- 即时 Web 网页
- 点击预览可看到对话界面
- 直接与智能体问答

## 后端 API

将智能体问答能力封装成 API，可在其他系统调用。

**适用场景**：
- 嵌入自有产品
- 与业务系统集成
- 批量调用

## 版本差异

2.1.0 以下版本的发布渠道和 Web/API 位置可能不同，具体参考对应版本帮助文档。

## 发布流程

```
智能体配置完成
    │
    ↓
点击"发布与集成"
    │
    ↓
选择发布渠道
    │
    ↓
配置渠道参数
    │
    ↓
发布上线
```

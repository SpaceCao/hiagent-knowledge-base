# 插件与MCP

扩展智能体能力，获取外部数据或执行动作。

## 插件类型

| 类型 | 说明 | 费用 |
|------|------|------|
| 官方插件 | 平台内置，可本地部署 | 免费 |
| 火山托管插件 | 火山引擎云服务 | 付费 |
| 三方插件 | 第三方云服务 | 付费 |
| 自定义插件 | 已有 API 封装 | 自定义 |
| MCP 插件 | 标准协议接入 | 看来源 |

## 官方插件示例

- **Browser** - 网页浏览
- **arxiv** - 论文检索
- **SQL** - 数据库查询

## MCP（Model Context Protocol）

Anthropic 推出的标准化协议，连接 LLM 与外部数据源/工具。

### MCP 接入方式

1. 平台内置 MCP 插件
2. 接入自定义 MCP 插件
3. 火山引擎云市场云端 MCP

## 自定义插件

将已有 API 打包成 HiAgent 插件，让智能体调用。

**适用场景**：
- 查询企业内部数据
- 调用业务 API
- 执行系统操作

## 内置工具/能力

| 工具 | 说明 | 可信度 |
|------|------|--------|
| Short-term memory | 短期记忆 | 中（视频 OCR） |
| Long-term memory | 长期记忆 | 中（视频 OCR） |
| Planning | 计划能力 | 中（视频 OCR） |
| Reflection | 反思能力 | 中（视频 OCR） |
| CodeInterpreter | 代码解释器 | 中（视频 OCR） |
| Search | 搜索 | 中（视频 OCR） |
| Calendar | 日历 | 中（视频 OCR） |
| calculator | 计算器 | 中（视频 OCR） |

## 选择决策

```
需要什么能力？
    │
    ├─ 搜索网页/论文 ────→ 官方插件（Browser/arxiv）
    │
    ├─ 查询数据库 ───────→ SQL 插件 或 自定义插件
    │
    ├─ 企业内部 API ─────→ 自定义插件
    │
    └─ 标准化工具接入 ───→ MCP 插件
```

# 插件与MCP

扩展智能体能力，获取外部数据或执行动作。

## 插件类型

| 类型 | 说明 | 费用 |
|------|------|------|
| 官方插件 | 平台内置，可本地部署 | 免费 |
| 火山托管插件 | 火山引擎云服务 | 付费 |
| 三方插件 | 第三方云服务 | 付费 |
| 自定义插件 | 已有 API 封装 | 自定义 |
| MCP 插件 | 标准协议接入 | 看来源 |
| 高代码MCP | 直接上传代码包到平台运行 | 自定义（v2.5.0+） |

## 官方插件示例

- **Browser** - 网页浏览（v2.4.0+: 支持wps、full_page_ocr）
- **arxiv** - 论文检索
- **SQL** - 数据库查询
- **Wait** - 暂停执行指定时间，1~180秒，适用异步轮询场景（v2.4.0+）
- **火山融合信息检索** - 联网问答Agent融合搜索，直接返回结果（v2.4.0+）
- **AIPPT** - 对接v2接口，先流式输出大纲再非流式输出内容（v2.4.0+）
- **搜狐热闻** - 新闻（v2.3.0+）
- **创可贴智能设计** - 设计（v2.3.0+）
- **板栗看板** - 看板（v2.3.0+）

## MCP（Model Context Protocol）

Anthropic 推出的标准化协议，连接 LLM 与外部数据源/工具。

### MCP 接入方式

1. 平台内置 MCP 插件
2. 接入自定义 MCP 插件
3. 火山引擎云市场云端 MCP（MCP Marketplace）
4. 高代码MCP - 直接上传代码包，命令中通过`HIAGENT_PKG_URI`引用包路径（v2.5.0+）

### MCP 特性

| 特性 | 说明 | 版本 |
|------|------|------|
| 流式输出 | MCP Server工具支持流式输出 | v2.2.0 |
| 同步失败日志 | 展示详细日志 | v2.5.0 |
| 插件统一MCP化 | 大部分插件统一迭代为MCP框架，存量不受影响 | v2.4.0 |
| Marketplace | 访问火山引擎云市场MCP并安装（部分可能不兼容） | v2.2.0 |

### MCP 不兼容场景

- 需要读本地文件系统
- 需要使用本地操作系统功能（浏览器、系统库等）
- local mcp server的启动命令非uvx/npx/docker

## 自定义插件

将已有 API 打包成 HiAgent 插件，让智能体调用。

**适用场景**：
- 查询企业内部数据
- 调用业务 API
- 执行系统操作

### 自定义插件增强（v2.5.0+）

| 功能 | 说明 |
|------|------|
| Bring Your Own Key | 开启后由使用者在编排时自主填写授权信息 |
| 动态Object入参 | 支持Object、Array\<Object\>作为入参叶子节点，可直接输入Json String |
| 请求体格式None | 为None时不传Content-type Header，忽略Body类参数 |
| INTEGER/NUMBER长度 | 最大支持2^53-1 |
| git运行环境 | 支持从git仓库拉取代码安装 |
| DSL/OpenAPI区分 | 导入导出文案优化区分 |

### 插件请求/响应格式（v2.3.0+）

- 请求体：json / form-data / x-www-form-urlencoded
- 响应体：json / text（text自动放到output出参字段）
- 注：流式输出工具、MCP工具不支持格式设置
- 超时时间可设为空，读取系统默认配置

## 选择决策

```
需要什么能力？
    │
    ├─ 搜索网页/论文 ────→ 官方插件（Browser/arxiv）
    │
    ├─ 查询数据库 ───────→ SQL 插件 或 自定义插件
    │
    ├─ 企业内部 API ─────→ 自定义插件
    │
    ├─ 标准化工具接入 ───→ MCP 插件
    │
    ├─ 自有代码逻辑 ────→ 高代码MCP（v2.5.0+）
    │
    └─ 异步轮询等待 ────→ Wait 插件（v2.4.0+）
```

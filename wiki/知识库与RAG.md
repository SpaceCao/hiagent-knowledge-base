# 知识库与RAG

让智能体基于私有知识回答问题。

## RAG 流程

```
用户提问 → 检索知识库 → 拼接 Prompt → 大模型回答
```

## 搭建流程

1. **文档准备**：清洗、统一格式、构造分隔符
2. **文档切割**：语义独立且完整的知识分片
3. **向量化存储**：存储到向量数据库
4. **检索**：匹配相关内容
5. **排序**：粗排 + 精排

## 检索方式

| 方式 | 说明 | 适用场景 |
|------|------|---------|
| 向量检索 | 语义相似度匹配 | 语义相关 |
| 全文检索 | 关键词精确匹配 | 精确关键词 |
| 混合检索 | 先全文后语义 | 综合效果最好 |

## 排序机制

| 阶段 | 说明 |
|------|------|
| 粗排 | 向量匹配，语义相似度 |
| 精排 | Reranker，更准确但更慢 |

**原因**：文本转向量有信息损失，Reranker 可弥补

## 配置参数

| 参数 | 说明 |
|------|------|
| 调用方式 | 强制模式（必查）/ Auto 模式（智能判断） |
| 检索方式 | 向量/全文/混合 |
| 召回分段数 | 检索多少个段落 |
| 相似度设置 | 阈值越高召回越少 |
| 扩展上下文 | 自动加入前后段落 |
| 无召回回复 | 无命中时的兜底回复 |

## 导入限制

- Excel 文件：约 25M
- 支持格式：Excel、CSV

## RAG Prompt 模板

```
# 你的任务
基于我提供给你的知识库回答问题

# 我的问题
{question}

# 知识库段落
{paragraphs}
```

## Agentic RAG

高级实践：知识库分路由 + 工作流取片段 + 智能体推理

```
用户问题
    │
    ↓
[路由判断] → [知识库A工作流] → 找到？→ 返回
    │              │
    │              └→ 未找到 → [知识库B工作流] → ...
    │
    └→ [知识库C工作流] → ...
```

**案例**：AI 辅导员，学生咨询学校事务

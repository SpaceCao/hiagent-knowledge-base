# 提示词设计

Prompt 是智能体的核心，定义角色、任务、约束和行为。

## Prompt 结构

```markdown
# 角色
[定义智能体身份和定位]

# 任务
[定义具体要完成的任务]

# 工具
## 插件名称
[什么场景下调用，如何调用]

## 知识库名称
[什么场景下使用]

# 要求
[具体约束和要求，何时使用什么工具]

# 少样本示例
## 问题
[示例问题]

## 回答
[示例回答]

# 注意事项
[强调正确做法，用于纠偏]

# 输出格式
[规定输出结构，如 markdown、json]
```

## 结构化字段

平台界面支持的结构化 Prompt 字段：

| 字段 | 用途 | 可信度 |
|------|------|--------|
| Role | 角色定义 | 中（视频 OCR） |
| Skills | 能力/工具列表 | 中（视频 OCR） |
| Constraint | 约束条件 | 中（视频 OCR） |
| Output | 输出目标 | 中（视频 OCR） |
| Format | 输出格式 | 中（视频 OCR） |
| Check | 自检规则 | 中（视频 OCR） |
| Claim | 强调项 | 中（视频 OCR） |

## 配置功能

| 功能 | 说明 |
|------|------|
| 编排配置 | 选择单 Agent / 多 Agent 模式 |
| 自动优化 | 用大模型优化 prompt，仅作参考 |
| 选择模板 | 导入已配置的 prompt 模板 |

## 调优要点

1. **注意事项很重要**：用于纠偏和稳定输出
2. **少样本示例**：格式化输出，引导行为
3. **输出限制**：4096 token 可能不够，需要技巧处理
4. **持续迭代**：根据输出效果不断调整

## 输出格式示例

```markdown
【题型】选择题
【分值】5分
【知识点】xxx
【题干】xxx
【答案】xxx
【解析】xxx
```

# HiAgent 智能体平台知识库

> 供 AI 智能体阅读和使用，指导在 HiAgent 平台上设计智能体方案。

## 快速开始

**入口文档**：[`SYSTEM_PROMPT.md`](SYSTEM_PROMPT.md)

包含：
- 设计决策树
- 配置检查清单
- Prompt 设计模板
- 用户需求输入模板
- 设计输出规范

## 设计决策树

```
用户需求
    │
    ├─ 依赖私有知识？ → 配置知识库（05-知识库与RAG实践.md）
    │
    ├─ 需要实时数据/外部动作？ → 配置插件/MCP（04-插件-MCP-工作流.md）
    │
    ├─ 有固定流程？ → 设计工作流（04-插件-MCP-工作流.md）
    │
    └─ 任务类型差异大？ → 拆分多智能体（06-发布集成与多智能体.md）
```

## 核心配置速查

### 模型选择

| 场景 | 类型 | 示例模型 |
|------|------|---------|
| 智能体底座 | 非推理类 | Claude-opus-4、Doubao-seed-1.6（关闭思考） |
| 文案/分析 | 推理类 | Deepseek-R1、Doubao-seed-1.6（开启思考） |

### 思维方式

| 方式 | 场景 |
|------|------|
| ReAct | 绝大多数场景 |
| deep_search | 检索增强 |
| Plan and Execute | 复杂多步骤 |

### 关键参数

- max_token: 4096
- 对话轮数: 30（最大）
- RAG 范围: 3

### Prompt 结构

```
# 角色
# 任务
# 工具
# 要求
# 少样本示例
# 注意事项
# 输出格式
```

### RAG Prompt 模板

```
# 你的任务
基于我提供给你的知识库回答问题

# 我的问题
{question}

# 知识库段落
{paragraphs}
```

## manifest.json 结构化信息

`manifest.json` 包含智能体可直接解析的结构化数据：

- `entry_point`: 入口文档
- `decision_framework`: 决策框架
- `models`: 模型列表
- `thinking_modes`: 思维方式
- `parameters`: 参数默认值
- `prompt_fields`: Prompt 字段
- `system_variables`: 系统变量
- `knowledge_base`: 知识库配置
- `workflow_nodes`: 工作流节点
- `capabilities`: 能力边界
